# EKU browser asset

The local `eku.glb` is converted from the user-supplied EKU sailor-uniform VPK model and materials. Large character assets and original VPK packages are intentionally excluded from this public source repository. The deployed server must include `public/models/eku.glb` before `npm run build`. Do not upload the source VPKs to the website. The site uses the fully dressed sailor-uniform variant.
